WEDDING INVITATION WEBSITE

1. Open index.html in a browser to preview the site.
2. Edit names, date, venue, times and story directly in index.html.
3. Change the countdown date in script.js.
4. Replace the four images in /images with your own photos. If you use JPG files, update the image filenames in index.html.
5. The RSVP form is currently a visual/demo form only. To receive real RSVPs, connect it to Google Forms, Formspree, or another form service.
6. Replace the View Location link (#) in index.html with your Google Maps link.
7. You can publish this folder using GitHub Pages, Netlify, or Vercel.
